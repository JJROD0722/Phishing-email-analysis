# Phishing Email Analysis Lab

# Overview
This project documents my investigation of a suspicious email advertising a PS5 Pro and GTA VI bundle.

# Tools
- Apple Mail for message and header inspection
- Microsoft Word for reporting

# Analysis
- Reviewed the sender and Reply-To addresses.
- Examined urgency and prize-related persuasion.
- Reviewed SPF, DKIM, and DMARC results.
- Inspected the link address without visiting it.
- Documented evidence and response recommendations.

# Findings
The unusual sender domain, authentication results of “none,” and unrelated link domain raised concern. These findings do not independently prove phishing.

# Verdict
Inconclusive; suspicious promotional email. The final link destination was not examined, so phishing and malware remain unconfirmed.

# Report
See the Case 001 PDF in this repository for the analysis and screenshots.

# Lessons Learned
Distinguish observations from assumptions, interpret authentication results carefully, and document uncertainty.
